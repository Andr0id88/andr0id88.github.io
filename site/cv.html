INTEGRATED PLATFORM OPERATIONSInternal project

Viti Center

From cluster requests to day-to-day platform operations.

I develop Viti Center, a Go-based operations platform with a central hub and distributed agents. It connects Kubernetes/Talos, KubeVirt, Ceph, Argo CD, ROR, and Slack/vitibot. Its scope includes cluster provisioning and lifecycle workflows, upgrade readiness, access and metadata management, migration tracking, and resilience diagnostics. It makes placement and anti-affinity risks visible and brings request progress and infrastructure findings into one operational workspace.

What I build

I develop Viti Center, a Go-based platform that connects infrastructure diagnostics with the workflows needed to operate Vitistack. It brings requests, provisioning, cluster lifecycle, access, and platform health into one workspace, alongside my contribution to the Tanzu-to-Vitistack migration.

Requests & provisioning

Connects Slack/vitibot requests to cluster creation, changes, deletion, access, and ROR project workflows. Tracks provisioning stages and supports completion notifications to requesters.

Cluster lifecycle

Combines Kubernetes and Talos inventory with upgrade readiness, version checks, and reviewed workflows for provisioning, scaling, and decommissioning clusters.

Tooling & access

Integrates Argo CD application health and drift with ROR inventory, project metadata, and access management. Provides controlled tooling actions and records administrative activity.

Infrastructure & resilience

Brings together KubeVirt placement and capacity, Ceph storage health, operator diagnostics, and networking information. Highlights workloads exposed to a single worker-node failure and makes placement and anti-affinity risks actionable.

Engineering scope

A Go hub and distributed agents collect information across sites and clusters. Operational workflows include permission checks, plan review, and audit records. Missing or stale reports remain visible, so incomplete information is not mistaken for a healthy platform.

Practical value

An operator can follow a request from its Slack entry into provisioning, investigate the resulting cluster and its tooling, and review migration progress or resilience findings in the same workspace. The project connects the operational context that would otherwise need to be assembled across separate systems.

Internal project at Norsk helsenett SF. Integration capabilities depend on configuration and access permissions.

Hivemind

I built Hivemind from scratch as an AI multi-agent workflow tool for Linux. It brings agent sessions, shared knowledge, task coordination, and review into a desktop and terminal workspace.
